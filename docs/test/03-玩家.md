# 3. 玩家 Player（17 个）

> 前置：[00-环境与工具](00-环境与工具.md) —— 客户端能起、ClickGui 能开、会改设置。
> 本册绝大多数是**服务端往返**类（改包 / 改容器 / 改 tick / 改视角），默认环境 **S**（任意服务器，单机开 LAN 也算）。
> 只有 `Freecam` / `FreeLook` / `ShulkerViewer` 可以纯单机（**L**）验完。

## 3.1 开测之前

**模块都在哪**：ClickGui → 第 3 列 `Player`（中文界面下是 `玩家`），主题色**橙色**，列头右上角计数 **17**。

> 找源码别找错目录：`AutoKit`、`ShulkerViewer` 的文件在 `misc/` 下（靠 `Category.Player` 进 `玩家` 列）；
> 反过来 `player/` 目录里的 `AirPlace` 属于 `World` 分类，不在本册。

**点击方式**（后面步骤里的「开 / 展开」都指这个）：

| 操作 | 效果 |
|---|---|
| 左键模块名 | 开关模块（聊天栏 `[+]` / `[-]`） |
| 右键模块名 | 展开 / 收起该模块的设置 |
| 左键布尔项 | 开关 |
| 右键带 `+` / `-` 的布尔项 | 展开 / 收起**子设置**（如 `TickShift`、`Fish`、`DoubleBreak`） |
| 左键拖滑块 | 拖数值；**右键滑块**：键入数值，回车确认 |
| 左键绑定项 | 显示 `Press a Key...`，按一个键绑定；`Delete` 清空；`Shift+左键` 在「切换 / 按住」间切换 |

每个模块设置面板最上面**固定两项**：`Key`（绑定键，默认无）、`Drawn`（是否进 HUD 数组列表，默认开）。

**默认是英文名**：`ClientSetting → Chinese` 默认关，GUI 里显示 `Timer` 而不是 `时间加速`。本册小节标题写成「English（中文）」方便对照。

**测之前先做的一件小事**：把 `Sorter`、`Replenish`、`AutoPot` 这类会动背包的模块留到最后测，先 `/gamemode creative` 备份一套物品，或者干脆用单独的测试存档。

### InteractTweaks（交互调整）
`player/InteractTweaks.java` · 环境：**S** · 风险：中

> **26.2 重点**：`Minecraft#itemUseCooldown` 变成了 `private int rightClickDelay`，现在用 accessor 读写。
> 「缩短使用物品冷却」的正确测法是**把 `UseDelay` 从 4 往 0 调**（默认 4 = 不动冷却）。
> `UseDelay` 的语义是「剩余冷却 ≤ 4 − UseDelay 时清零」，所以 4 → 什么都不做，0 → 一有冷却就清。

| 项 | 内容 |
|---|---|
| 前置 | 一堆末影珍珠 / 雪球 / 鸡蛋（可连续右键），一块可挖的墙，几个投掷物 |
| 关键设置 | `UseDelay`（默认 **4**，0~4）、`NoMineAbort` / `NoMineReset` / `NoMineDelay`（默认全关）、`NoEntityTrace`（投掷物不挡准星，默认开）+ `OnlyPickaxe`（默认开）、`MultiTask`（边吃边挖，默认开）、`Respawn`（死亡自动重生，默认开）、`IgnoreBedrock`（默认关）、`NoInteract`（默认关）、`SwitchEat`（默认关）+ `Sword` / `Pickaxe`、`Reach`（默认关）+ `BlockRange` / `EntityRange`（默认 5） |
| 步骤 | 1. 开 `InteractTweaks`，`UseDelay` 留 4，对空地连点右键扔珍珠，记 **10 秒扔出几颗**（基线）<br>2. 把 `UseDelay` 拖到 0，同样 10 秒再数一遍<br>3. 手持镐对墙：按住右键（放方块/使用）同时按住左键挖 —— 看能不能同时进行（`MultiTask`）<br>4. 往脚下丢一颗珍珠/雪球，隔着它挖后面的方块（`NoEntityTrace`）<br>5. 切生存 `/kill`，看死亡界面<br>6. 打开 `Reach`，站 6 格外点方块（`BlockRange` 5 应该点不到，调到 7 再试） |
| 预期 | `UseDelay=0` 时右键间隔从原版 4 tick 掉到接近 1 tick，10 秒扔出的数量**明显多于**基线，但仍受服务端限制；`MultiTask` 开时能一边进食一边挖；投掷物不再挡住准星命中；死亡界面出现后自动重生；`Reach` 打开后 6~7 格可以点到方块 |
| 失败信号 | `UseDelay` 从 4 改到 0 **完全没区别**（accessor 没注入 → 查启动日志 `InvalidMixinException` / `@Accessor` 报错）/ 改成 0 后被服务端踢（发包过快）/ 开了 `NoMineAbort` 松手后还在挖 / `Reach` 开了还是 4.5 格 / 死亡后卡在死亡界面 |
| 结果 | [ ] ✅　[ ] ⚠️　[ ] ❌ |

## 3.4 本册回归优先级（20 分钟版）

时间只够跑一遍时，按这个顺序，**只测这 6 个**：

| 顺序 | 模块 | 用时 | 只看这一条 |
|---:|---|---:|---|
| 1 | **AutoTool** | 5 min | 准星对准石头按下左键，是否**在开始挖之前**切到镐；连点石墙，方块是否被秒挖（秒挖 = 冷却 bug） |
| 2 | **InteractTweaks** | 4 min | `UseDelay` 4 → 0，10 秒内扔出的珍珠数量是否明显变多 |
| 3 | **PacketMine** | 3 min | 生存模式点一下方块：出进度框 → 100% → 方块碎；不被服务端拉回 |
| 4 | **NoFall** | 3 min | 20 格跳下不掉血；`Packet` / `Grim` 两种模式各跳一次 |
| 5 | **ShulkerViewer** | 3 min | 悬停装满东西的潜影盒，预览底板 + 27 格是否画出来；中键能否直接打开 |
| 6 | **AutoArmor** | 2 min | 站定、无容器，背包放更好的甲，是否自动穿上（带绑定诅咒的不穿） |

跳过 `Sorter` / `Replenish` / `AutoPot` / `AutoPearl`：它们会动背包或发容器包，需要先备份存档，放第二轮。
`Freecam` / `FreeLook` / `Yaw` 是纯本地视角类，坏了也一眼能看出，随手点一下即可。
