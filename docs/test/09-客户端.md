# 9. 客户端 Client（10 个）

> 前置：[00-环境与工具](00-环境与工具.md)。
> 本册几乎全是 GUI / 设置 / HUD 类，**纯本地就能测**：环境 **L**（单机创造存档）。
> 例外：`TextRadar` 需要第二个玩家；`Baritone` 需要装 Baritone；`AntiCheat` 本身没有画面，只能通过**其它模块的行为**间接验。

**这一册的第一件事不是测模块，是测布局**：26.2 把分类从 7 个重组成 9 个，
ClickGui 是 1.21.1 的 7 列原始布局（本轮按用户要求回退了「网格 + 列内滚动」的改动），列坏了整个客户端都没法用。
所以顺序是：9.2 布局（必须全过）→ 9.3 模块。

## 9.1 先统一操作说法

后面步骤里出现的词，都指这套操作：

| 说法 | 实际操作 |
|---|---|
| 开 GUI / 关 GUI | 按 **右 Shift**（`ClickGui` 的 `Key` 默认就是 `RSHIFT`，全客户端只有它默认带键）；`Esc` 也能关 |
| 开某模块 | 左键点模块名（聊天栏出现 `[+]`） |
| 展开设置 | **右键**点模块名（行内出现设置列表） |
| 展开子项 | **右键**点带 `+` 的项（如 `TickShift`、`Fish`、`colors`），`+` 变 `-` |
| 改滑块 | 左键拖；**右键滑块**改成键入数字，回车确认 |
| 绑键 | 左键点 `Key` → 显示 `Press a Key...` → 按一个键；`Delete` 清空；`Shift+左键` 切「切换 / 按住」 |
| 改颜色 | 带开关的颜色项：左键开关、**右键展开取色板**；取色板里左键拖色板/色相/透明度，底部有 `copy` / `paste` / `sync` 三个可点文字 |
| 移动整列 | 左键拖列头（拖过之后这一列就不再自动排列） |
| 拖动 | 按住列头拖动可移动整列（1.21.1 原始行为） |
| 滚轮 | 鼠标在某展开列**列体内** → 只滚这一列；列体外 → 整屏上下平移；**Shift + 滚轮** → 整屏左右平移 |

两个固定事实，别当 bug：

- 每个模块设置面板最上面固定两项 `Key`、`Drawn`。
- 默认是**英文**界面（`ClientSetting → Chinese` 默认关）；本册小节标题写成「English（中文）」方便对照，GUI 里要按英文名找。
- `AntiCheat` / `Colors` / `ClientSetting` / `Baritone` 这 4 个的「开关」是被强制写死的（永远算「开」），点它们不会变色，别当成开关坏了；`HUD` 是普通开关。
- `ClickGui` 也是普通开关，但它开 = 打开 GUI、GUI 一关就自动关回去，所以你会看到它在列里**亮一下又灭** —— 正常。

## 9.2 布局检查（1.21.1 的 7 列原始布局）

### 9.2.1 七列顺序与计数

按右 Shift 开 GUI，从左到右逐列对（**单排 7 列**，列宽 93px、间距 1px、首列从左侧 10px 开始）：

| 顺序 | 列头 | 模块数 |
|---:|---|---:|
| 1 | `Combat` | **23** |
| 2 | `Misc` | **20** |
| 3 | `Render` | **24** |
| 4 | `Movement` | **23** |
| 5 | `Player` | **16** |
| 6 | `Exploit` | **18** |
| 7 | `Client` | **10**（见下方注意） |

合计 **134**（`Client` 少 `Baritone` 时 133）。

> **两件必须提前知道的事，否则一定误报**：
> 1. **7 列是单排，不换行。** 列宽 93px，7 列共约 660px。当 `GUI 缩放 3`（逻辑宽度 640）时，
>    最右边的 `Client` 列会有约 25px 超出屏幕右边缘 —— 这是 1.21.1 的原始行为，**不是 bug**。
>    想看全就用**滚轮**整屏左右平移（`Shift+滚轮`）或把 GUI 缩放调到 2。
> 2. **`Client` 列可能只有 9 个模块。** `BaritoneModule` 只在检测到 `baritone.api` 包时才注册（26.2 还没有 Baritone），
>    所以标准测试包里 `Client` 列**没有 `Baritone` 这一项**。这不是丢模块。

| 项 | 内容 |
|---|---|
| 步骤 | 1. 右 Shift 开 GUI<br>2. 数总共几列、每列列头文字<br>3. 逐列右键展开，数里面的模块数<br>4. 按住任意列头拖动，看整列是否跟着走<br>5. 滚轮 / `Shift+滚轮` 看整屏是否能上下 / 左右平移<br>6. 右键列头，看能否折叠/展开 |
| 预期 | 7 列齐全、顺序与上表一致（`Combat` 第一、`Client` 最后）；每列模块数与上表一致；列头可拖动；滚轮整屏平移、`Shift+滚轮` 左右平移；右键列头折叠后列体收起、再右键展开 |

### 9.2.2 列内容超出时的表现

> 1.21.1 的原始布局**没有列内滚动**：一列 24 个模块全展开会往屏幕下方延伸，超出屏幕就只能靠整屏平移（滚轮）看。
> 这是预期行为，不是 bug —— 本版按用户要求回退了「网格 + 列内滚动」的改动。

| 项 | 内容 |
|---|---|
| 前置 | `GUI 缩放` 调到 2，屏幕高度 1080 左右 |
| 步骤 | 1. 右键展开 `Render` 列（24 个，最长）<br>2. 一直滚轮向下，看能否看到 `Zoom`（字母序最后）<br>3. 观察展开后列体是否与下方内容重叠 |
| 预期 | 整屏一起向上平移，能看到列尾；列与列之间不会互相覆盖 |
| 失败信号 | 滚轮完全没反应 / 平移后列错位 / 模块画到别的列上 |
| 结果 | [ ] ✅　[ ] ⚠️　[ ] ❌ |

### ClickGui（点击界面）
`client/ClickGui.java` · 环境：**L** · 风险：低（但坏了一整屏都用不了）

| 项 | 内容 |
|---|---|
| 前置 | 无。这一节只测 GUI 本体，9.2 的布局检查也算它的一部分 |
| 关键设置 | `AutoSave`（关 GUI 时存配置，默认开）、`Font`（开）、`Shadow`（开）、`Sound`（开）+ `SoundPitch`（1.0）、`Height`（行高，3）、`TextOffset`（0）、`TitleOffset`（-1）、`Alpha`（180）、`HoverAlpha`（240）、`TopAlpha`（240）、`Fade`（开）+ `Length`（250）+ `Easing`（`Expo`）、`Blur`（**关**）+ `Radius`（10）、`Elements`（关）+ `Line`（开）+ `Gear`（颜色项，开关关）、`Colors`（关）+ 一堆颜色子项 |
| 步骤 | 见下方逐项表 |
| 结果 | [ ] ✅　[ ] ⚠️　[ ] ❌ |

**逐个设置项的预期**（按面板顺序）：

| 设置项 | 默认 | 操作 | 预期现象 |
|---|---|---|---|
| `AutoSave` | 开 | 改任意设置后关 GUI，重启客户端 | 设置保住了；关掉后改设置再重启会**丢**（不自动存盘） |
| `Font` | 开 | 关掉它 | 所有 GUI 文字从自带字体切成原版字体（明显变宽/变高）；再打开恢复 |
| `Shadow` | 开 | 关掉 | 文字阴影消失，字变「薄」；只在 `Font` 下也生效 |
| `Sound` | 开 | 左键任意模块 | 每点一下有 `UI_BUTTON_CLICK` 音效；关掉后完全静音 |
| `SoundPitch` | 1.0 | 调到 0.5 / 2.0 | 音高变低沉 / 变尖（`Sound` 关时无感） |
| `Height` | 3 | 调到 7 | 每个模块行明显变高（行高 = 10 + Height），一屏能放的更少 |
| `TextOffset` | 0 | 调到 5 / -5 | 所有按钮文字整体上移 / 下移（过了会跟行底边重叠） |
| `TitleOffset` | -1 | 调到 3 | 列头标题与模块计数的竖直位置整体下移 |
| `Alpha` | 180 | 调到 40 | 已开启（高亮）模块的底色变淡；调到 255 变实色 |
| `HoverAlpha` | 240 | 悬停在某个已开启模块上 | 悬停时的底色 alpha；与 `Alpha` 对比能看出「悬停更亮」 |
| `TopAlpha` | 240 | 调到 60 | **列头**底色变透明（列体不变） |
| `Fade` | 开 | 关掉后开关 GUI | 开：关闭 GUI 有一段淡出；关：瞬间消失 / 瞬间出现，没有淡入淡出 |
| `Length` | 250 | 调到 1000 | 淡出时长变成约 1 秒（`Fade` 开才有感） |
| `Easing` | `Expo` | 换 `Linear` / `CubicInOut` | 淡出的节奏曲线变化：`Expo` 前快后极慢，`Linear` 匀速 |
| `Blur` | **关** | 打开它，展开任意列 | **只有展开的列体矩形**变模糊，世界其余部分清晰；拖 `Radius` 从 10 到 100 模糊更重 |
| `Radius` | 10 | 调大调小 | 模糊半径（采样步数）变化；`Blur` 关时无感 |
| `Elements` | 关 | 左键点它 | 只是**展开/收起** `Line`、`Gear` 两个子项用的父开关，点它本身不改变画面 |
| `Line` | 开 | 关掉 | 模块之间、列体左右下边的分隔线消失 |
| `Gear` | 颜色项，开关**关** | 先左键打开开关，再右键展开取色板 | 打开后每个模块行右端出现 `+` / `-`（表示有无子设置）；关掉就只剩名字 |
| `Colors` | 关 | 左键点它 | 同 `Elements`：只是展开/收起颜色子项，**不关颜色生效** |
| ↳ `Color` | 白（且 `sync` 默认开） | 展开取色板取一个绿色 | 列头底色、已开启模块高亮色**整体变绿** —— 但注意它默认 `sync` 开着，实际取的是 `Colors → Color`（客户端主色）的值；想让它独立，先在取色板里点 `sync` 关掉同步 |
| ↳ `HoverColor` | 半透明灰 `0x88555555` | 悬停未开启的模块 | 悬停底色变化 |
| ↳ `DefaultColor` | 全透明白 | 调成不透明深灰 | 未开启模块的底色变成深灰（默认是几乎看不见的透明） |
| ↳ `DefaultTextColor` | 白 | 调成黄色 | 未开启模块的文字变黄 |
| ↳ `EnableTextColor` | 白 | 调成黑色 | 已开启模块的文字变黑 |
| ↳ `BackGround` | 开关**开**，`0x77000000` | 左键关掉开关 | 展开列的列体半透明黑底板消失（会看到背后的世界） |
| ↳ `Tint` | 开关**开**，黑 alpha 36 | 左键关掉开关，然后**打开背包** | 开：**任何**界面（背包/箱子/暂停）背后都有一层黑→红渐变遮罩；关：遮罩消失（此时仍会因 `ClientSetting → Darkening` 变暗） |
| ↳ `End` | 红 alpha 80 | 改成蓝色 | `Tint` 渐变的终点色变蓝（配合 `Tint` 看全屏渐变） |

> `Blur` 的实际实现是「按矩形区域模糊」的自定义后处理（`alien:blurarea`）。
> 如果着色器链不可用，会**回退成原版整屏模糊** —— 那时看到「整个世界都糊了」，
> 记 ⚠️ 并注明「回退到全屏模糊」，不算 `Blur` 完全不工作。

## 9.4 本册回归优先级（20 分钟版）

这一册的「坏」是**一次坏一片**，所以优先级跟别的册子不一样：先布局，再字体，最后模块。

| 顺序 | 项目 | 用时 | 只看这一条 |
|---:|---|---:|---|
| 1 | **7 列布局** | 4 min | 7 列齐全（Combat/Misc/Render/Movement/Player/Exploit/Client）、顺序对、`Combat` 计数是 `23`；记住默认是 **5+4 两行** |
