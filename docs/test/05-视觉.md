# 5. 视觉 Visual（11 个）

> 本册管 `src/main/java/dev/luminous/mod/modules/impl/render/` 里**画面 / 镜头改造**类的 11 个模块。
> **GUI 里它们同样都在 `Render` 列**（ClickGui 是 1.21.1 的 7 列原始布局，没有单独的「视觉」列）——
> 本册只是为了「一次只测一类」按功能拆出来的，所以 `Shader.java`（`ShaderModule`）和 `ESP.java` 在同一个文件夹、同一个 GUI 列里，却分属两册。
> 环境准备在 [00-环境与工具](00-环境与工具.md)；本册几乎全是 **L（单机创造）**。

## 5.1 适用范围

**覆盖**：改「整帧画面 / 镜头 / 投影 / 手持物 / 准星」的东西。

| 主题 | 模块 |
|---|---|
| 后处理 / 画面合成 | `Shader` `NoRender` `Ambience` |
| 方块渲染管线 | `Xray` |
| 镜头 / 投影 | `Fov` `AspectRatio` `CameraClip` `MotionCamera` `Zoom` |
| 手持物 / HUD 绘制 | `ViewModel` `Crosshair` |

**不覆盖**：`ESP` / `NameTags` / `Chams` 等 13 个信息可视化模块，见 [04-渲染](04-渲染.md)。

**交叉污染（测之前先确认这些是关的）**：

| 干扰源 | 会污染谁 |
|---|---|
| `Shader` | **一切**。它接管 `GameRenderer` 里手部之后的后处理合成，并 cancel 原版 `doEntityOutline` 的第二次混合。开着它看别的模块，等于隔着一层滤镜判断 |
| `NoRender` | `Shader`（`Invisible`/`Items` 会把目标实体掐掉，`Shader` 就没东西可描）、`Ambience` |
| `Ambience` | `Xray`（雾/亮度过亮会看不出"矿石剩没剩"） |
| `Fov` × `Zoom` × `AspectRatio` | 三个都在 `extractCamera` 里重算同一个投影矩阵，同时开时按 `Fov → Zoom → AspectRatio` 的顺序生效，单测时必须关掉另两个 |
| `Freecam` / `FreeLook`（玩家册） | `CameraClip` / `MotionCamera`：都在 `Camera#alignWithEntity` 上改位置，`Freecam` 优先级最高 |

## 5.4 本册特有陷阱

**① 先只开一个模块。**
本册的模块全都改「最终画面」，叠加起来无法归因：`Shader` 会替掉原版发光描边、`NoRender` 会掐掉实体和粒子、`Ambience` 会改 lightmap 和天空色、`Fov`/`Zoom`/`AspectRatio` 改同一个投影矩阵。
→ 每节开始前把 **`Render` 列** 全灭，只留被测模块（需要靶子时再单独开 `Misc/FakePlayer`）。

**② 截图前按 `F1`，但准星和 `Shader` 的手是例外。**
`F1` 藏掉 HUD/数组列表/药水图标，画面才干净。但：
- `Crosshair` 画在 `Hud#extractCrosshair` 里，**`F1` 会把自定义准星一起藏掉**——验准星时不能按 `F1`，改成关 `HUD` 模块或临时把聊天栏清空。
- `Shader` 的手部剪影在 `guiRenderState.isHudHidden` 为真时**直接跳过**——`F1` 下"手不发光"是正常的，别记成 bug。

**③ 画面没变化，先按 `F3+T`。**
26.2 的后处理链（`Shader` 的 7 条 `alien:outline/pulse/smoke/gradient/snow/flow/rainbow` 与 `alien:blurarea`）在资源重载后由原版 `ShaderManager` **close 掉旧 chain**，Alien 靠 `GpuBuffer#isClosed()` 判定失效再重新加载。
所以：切资源包 / `F3+T` 之后如果效果没了，先等一帧再做判断；反过来，某个模式"切了没反应"也先 `F3+T` 一次再下结论。

**④ `Shader` 的 7 条链都输出到 `alien:glow`，再按 alpha 混回主画面。**
也就是说：**它们看起来像"描边/手部特效"，不是全屏滤镜**。alpha 来自「被选中实体的原版发光描边」和「你重绘的手部剪影」，没有 alpha 的地方**一点都不会变**。
想要整屏变色，用 `Ambience → Filter`，不是 `Shader`。

**⑤ `NoRender` / `Ambience` 的一部分是"本地拦截"，服务端状态不变。**
天气、时间、失明、反胃、药水图标都只是客户端不显示/不改；关掉模块后要等服务端下一次同步才回到"正常"。测试时别用"服务端还认为在下雨"当失败。

**⑥ `F1` 隐藏的不只是 HUD。**
`FireOverlay` / `WaterOverlay` / `BlockOverlay` 这些叠加层也画在 `Hud#extractRenderState` 的 `!isHidden` 分支里，`F1` 一按就都没了——验 `NoRender` 的这三个子项时同样不能按 `F1`。

> **26.2 迁移要点（测之前先知道）**
> 1. 旧版 1.21 的 `assets/minecraft/shaders/post/*` 与 `program/*` 已全部删除，26.2 只读 `assets/alien/post_effect/*.json`（`PostChainConfig`）+ `assets/alien/shaders/post/*.fsh`。**7 个模式 = 7 条 chain**：`alien:outline` `alien:pulse` `alien:smoke` `alien:gradient` `alien:snow` `alien:flow` `alien:rainbow`。
> 2. 颜色/半径/时间这些参数不在 GLSL 里写死，而是每帧通过 `PostPass#customUniforms` 写 std140 buffer（`Time/Color/Radius/Divider/MaxSample/Quality/Alpha…`）。所以"改 `Color` 画面不变"= uniform 写失败，不是着色器写错。
> 3. `Mode` 里的 `Solid` 对应 chain 名 `outline`（`ShaderManager.idFor`），GUI 里看到的是枚举名，不是 chain 名——对日志时别找 `Solid`。
> 4. 手部是 26.2 新增的离屏路径（`alien:hands`）：`ShaderManager` 用 `ItemInHandRenderer#submitHandsWithItems` 把手重画到离屏 target。**"手会发光"本身就是这次迁移最值得验的一条**；手不亮说明这条路径没走通。
> 5. **顺带一句 `ClickGui → Blur`**（09 客户端册）：它和本模块共用同一套 `PostChain` 机制，走 `alien:blurarea` 做**区域**模糊（shader 里按 scissor 判定，最多 **8 个矩形**），不是全屏模糊。超过 8 个可见组件时只有前 8 个矩形会糊，其余保持清晰——这是设计上限。

## 5.6 本册回归优先级（20 分钟版）

时间不够时只跑这 4 个，它们分别卡住「整条后处理链 / 投影矩阵 / 视野缩放 / 画面元素抑制」四条 26.2 高风险链路：

| 顺序 | 模块 | 时长 | 只测这一件事 |
|---|---|---:|---|
| 1 | `Shader` | 8 min | 7 个 `Mode` 各切一遍，**每个都要看得出画面在动**；`Solid` 改 `Color` 立刻变色；`Hands` 开时手有光 |
