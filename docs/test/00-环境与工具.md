# 0. 测试环境与工具（26.2）

> 本文是所有分册的前置条件。**没按本文准备好环境，后续测试结果一律不可信。**

## 0.1 客户端运行方式

### 方式 A：开发环境直跑（推荐，能看日志）

```powershell
$env:JAVA_HOME = "C:\Program Files\Zulu\zulu-25"
cd "D:\Poject\TEAMTCP\AlienClient-OpenSource-release"
.\gradlew runSmokeClient --offline
```

- `--offline` **必须带**：本机到 `libraries.minecraft.net` 的下载会「连上但不返回」，不加会永久卡住。
- `runSmokeClient` 已配置 `--quickPlaySingleplayer "New World"`，直接进存档。
- 控制台日志同时会出现在终端里，模块报错、mixin 冲突都看这里。

### 方式 B：装进正式客户端

```powershell
.\gradlew build --offline
```

产物：`build/libs/alien-5.0.jar` → 丢进 `.minecraft/mods/`（Fabric Loader 0.19.5 + Fabric API 0.161.0+26.2）。

### 必备前置检查

| 检查项 | 期望 |
|---|---|
| 启动日志含 `Loading Minecraft 26.2 with Fabric Loader 0.19.5` | ✅ |
| 启动日志无 `InvalidMixinException` / `@Redirect conflict` | ✅ |
| 左上角出现水印 / HUD | ✅ |
| 按 `Y`（或 `RSHIFT`，看 ClickGui 的 Key 设置）能开 ClickGui | ✅ |

> ClickGui 的默认键是 **右 Shift**（`ClickGui` 模块的 `Key` 设置），`Y` 只是常见自定义。

## 0.2 三档测试环境（按模块风险选择）

| 档位 | 环境 | 适用 | 风险 |
|---|---|---|---|
| **L — 本地** | 单机创造/生存世界，`对局域网开放` 关闭 | 纯客户端渲染、GUI、HUD、镜头、材质类 | 无 |
| **S — 服务器** | 任意服务器（单机开 LAN 即可）或离线 Fabric 服 | 需要服务端往返的移动/玩家/杂项/漏洞类 | 低，但公共服有反作弊 |
| **C — 战斗专用服** | 独立 Fabric 26.2 服，关反作弊，`online-mode=false` | **全部 23 个 Combat 模块** | 高：公共服会封号 |

> **为什么战斗类必须上专用服**：`Aura` / `AutoCrystal` / `Burrow` / `PistonCrystal` 这类模块的行为是**发包序列**，
> 客户端单机（集成服）里 `minecraft.isLocalServer()` 为真，很多「服务端才会拒绝」的动作会被直接放过，
> 于是「单机测试通过」≠「真服可用」。反过来，公共服的 NCP/Matrix/Vulcan 会把正常测试判成作弊，
> 你看到的现象是「被踢/回弹」，无法区分是模块坏了还是被反作弊拦了。

## 0.3 搭建战斗专用服（一次性）

### 步骤 1：起一个 Fabric 26.2 服务器

```powershell
# 1) 建目录
mkdir C:\mc-test-26.2
cd C:\mc-test-26.2

# 2) 下载 26.2 官方服务端（Mojang version manifest 里取 26.2 的 server 下载地址）
#    浏览器打开 https://piston-meta.mojang.com/mc/game/version_manifest_v2.json
#    找到 "id": "26.2" 的 url，再打开它，取 downloads.server.url，下载为 server.jar

# 3) 装 Fabric Loader 0.19.5
#    下载 https://maven.fabricmc.net/net/fabricmc/fabric-installer/<latest>/fabric-installer-<latest>.jar
java -jar fabric-installer.jar server -mcversion 26.2 -loader 0.19.5 -downloadMinecraft

# 4) 放 Fabric API
#    fabric-api-0.161.0+26.2.jar  →  C:\mc-test-26.2\mods\
```

### 步骤 2：`server.properties` 关键项

```properties
online-mode=false          # 允许离线小号，方便双开测试
pvp=true
difficulty=hard            # 战斗模块要真实伤害
spawn-protection=0
allow-flight=true          # 否则 Fly / PacketFly 会被踢，无法测
enable-command-block=true
view-distance=10
simulation-distance=8
```

> `allow-flight=true` 是**必须**的：默认 `false` 下服务端会把 `Fly` / `PacketFly` / `ElytraFly` 判成
> "Flying is not enabled on this server" 直接踢人，你会误判成模块坏了。

### 步骤 3：关掉反作弊

如果是 Paper/Purpur 系服务端，`config/paper-global.yml` 里关 `anti-xray` 之外的反作弊插件；
如果装了 NCP/Matrix/Vulcan/Grim，**测试前全部卸载**。Grim 尤其严格，会在 `Aura` 的
`attack` 包频率上直接 `setback`。

### 步骤 4：第二个玩家

战斗模块需要**真实的服务端实体**当靶子。三种办法，优先级从高到低：

1. **双开客户端**：同一台机器开第二个 Minecraft（离线号 `Tester2`），进同一个服。
   缺点：吃内存，建议客户端 `视距 6` 以下。
2. **Alien 自带 `FakePlayer`**（`Misc` 分类）：客户端侧假人。
   开关命令是 `;fakeplayer`（**开 = 生成、关 = 删除**，没有 `add`/`remove` 子命令；还有 `;fakeplayer record` / `;fakeplayer play`）。
   适合测 `Aura` 的选靶/转向、`Criticals` 的暴击、`KillEffect`；
   **不适合**测 `AutoCrystal` / `Burrow` / `Surround` 这类需要服务端真实交互的模块（假人不收服务端包）。
   > 注意：假人吃图腾时会真的扣你副手那一格（`replaceWith` 共享同一个 `ItemStack`），别拿唯一一叠测。
3. **Alien 自带 `Bot`**（`Misc` 分类）：**它不会攻击你** —— 它是 12 种自动化脚本（默认 `Mode=AutoTrade`），
   全代码里唯一的 `attack` 是 `XinDupe` 杀自己的羊驼。
   所以**防守类测试（`AutoTrap` / `Surround` / `SelfTrap`）请用第二个真玩家**，不要指望 Bot 打你。

### 步骤 5：基准地形

战斗模块大量依赖「坑（Hole）」和「水晶」。进服后执行：

```
/gamemode creative
/give @s minecraft:obsidian 256
/give @s minecraft:end_crystal 64
/give @s minecraft:totem_of_undying 64
/give @s minecraft:netherite_sword
/give @s minecraft:enchanted_golden_apple 64
```

然后在平地上挖/搭一个标准测试场地：

```
# 4 个 1x1 的坑（深 2 格），坑心间距 3 格 —— Aura/Surround/HoleFiller 都用它
/fill ~0 ~-2 ~0 ~0 ~-1 ~0 minecraft:air
```

> 更省事：`/setblock` 手搭 3x3 的石台，中间挖 1x1 两格深，就是标准 hole。

## 0.4 测试记录规范

每个模块按分册里的表格逐项打勾，**失败必须记录**：

| 字段 | 说明 |
|---|---|
| 结果 | ✅ 通过 / ⚠️ 部分可用（功能在但效果不对）/ ❌ 失败（崩/无效/报错） |
| 现象 | 一句话描述你看到的（例：模块开了但实体没被瞄准） |
| 日志 | 客户端 `.minecraft/logs/latest.log` 里 `[Alien]` 或 `Exception` 相关行 |
| 环境 | L / S / C 哪一档，服是什么端 |

> 客户端崩溃 → `run/crash-reports/` 或 `.minecraft/crash-reports/`；
> 只报错不崩 → 抄 `latest.log` 里该模块名附近的栈。

## 0.5 快速回归顺序（时间不够时只跑这些）

1. **启动 + ClickGui**：7 列是否都显示（Combat / Misc / Render / Movement / Player / Exploit / Client，单排、可拖动）、开关模块是否即时生效。
2. **HUD / 水印 / 数组列表**：文字是否能读、有没有乱码。
3. **ESP / Tracers / NameTags / HoleESP**：这是最容易一眼看出坏没坏的一类。
4. **Fly / Speed / NoFall / Velocity**：移动类翻车最容易导致「被踢」。
5. **Aura + AutoCrystal**：战斗两大件，上专用服各测 5 分钟。
