## 为什么战斗类要单独一册

- 战斗模块的正确性 = **发包序列** + **服务端响应**。单机（集成服）里 `isLocalServer()` 为真，
  很多服务端本该拒绝的动作会被放过，于是「单机通过」毫无意义。
- 公共服的 NCP / Matrix / Vulcan 会把测试行为判成作弊，你看到的「被踢、回弹、伤害为 0」
  分不清是模块坏了还是被反作弊拦了。
- 所以：**Combat 的 23 个模块，一律在 `allow-flight=true` + 无反作弊 + 有第二个玩家的专用服上测。**

## 总进度表

测完一项就把 `[ ]` 改成 `[x]`。

### 第一轮：冒烟（30 分钟，必做）

- [ ] 客户端启动，日志出现 `Loading Minecraft 26.2 with Fabric Loader 0.19.5`
- [ ] 日志无 `InvalidMixinException` / `@Redirect conflict` / `NoSuchMethodError`
- [ ] ClickGui 能开，**7 列全部显示**（Combat / Misc / Render / Movement / Player / Exploit / Client，单排）
- [ ] 列能按住列头拖动；右键列头能折叠/展开
- [ ] 开关任意模块，聊天栏有 `[+]` / `[-]` 提示，且配置能保存（重启后仍生效）
- [ ] HUD / 水印 / 数组列表文字正常（无乱码、无方块字）

### 第三轮：已知风险点复测

这些是 26.2 迁移中最可能出问题的地方，即使前面全过也要单独确认：

- [ ] **后处理着色器**：`Shader`（视觉分类）每种模式都要切一遍，画面必须真的变化
- [ ] **ClickGui 模糊**：`ClickGui → Blur` 打开后，GUI 背后的世界要真的变模糊
- [ ] **NameTags**：其他玩家头顶的自定义名牌是否绘制在正确位置、跟随移动
- [ ] **Chams / PopChams**：26.2 没有全局着色颜色，颜色是否生效
- [ ] **聊天**：`ChatAppend` 后缀、聊天淡出是否正常
- [ ] **副手切换**（战斗分类 `Offhand`）：能否把背包物品换到副手
- [ ] **发包类**（`Blink` / `Velocity` / `PingSpoof`）：是否仍然生效而不是「开了没反应」

## 失败上报模板

```
模块：Aura
环境：C 专用服（Fabric 26.2，allow-flight=true，无反作弊）
结果：⚠️ 部分可用
现象：能锁定目标并转向，但攻击频率明显低于设置值（12 CPS 设了只打出 3~4 次）
日志：latest.log 里 [Alien] 无异常；f3+L 看包体，Attack 包间隔约 240ms
复现：站桩对假人，CPS 设 12，观察 10 秒
```

> 只报错不崩 → 抄 `latest.log` 里模块名附近的栈；
> 崩了 → `crash-reports/` 整个文件。
